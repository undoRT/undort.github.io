Detailed Description

Serializes a LibraryDescriptor back to JSON.

The serializer is the reverse side of LibraryLoader: it converts the in-memory model into a canonical JSON document (v1.0). The canonical output preserves the semantic content of the descriptor and is deterministic, so it can be used for round-trip tests and comparisons; whitespace/formatting is not guaranteed to match the input document.
