Detailed Description

Emit C++ code from the parsed AST.

The CodeGenerator visits the TranslationUnit and produces a pair of strings: a C++ header and a C++ source. The generator targets the small mpscpp runtime provided in undoCore/include/undoCore/types.hpp.

Attach a semantic analysis, or detach it with null.

When present, the generator consumes the decorated AST (Expr::resolvedTypeId, Expr::symbolId, CallExpr::calleeSymbolId) and the SymbolTable instead of re-inferring names, types and signatures from the syntax. The semantic components are rebuilt because the bridge holds the analysis by pointer, so a bridge built before the analysis was attached would keep querying a null table and silently degrade to syntactic inference.
