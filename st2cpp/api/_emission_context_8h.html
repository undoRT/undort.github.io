Detailed Description

Shared state of a code generation run.

The emitter for declarations, the emitter for expressions and statements, and the emitter that assembles the files all read and write the same state: the two output streams, the indent, the scope stack, the maps collected while walking the translation unit, and the collaborators built from the semantic analysis. That state lives here so a single object owns it and the emitters only borrow a reference to it.

EmissionContext also carries the small queries the emitters make over its collaborators (type spelling, semantic bindings, dependency ordering, library includes) and the indent helpers, so an emitter never has to reach through the context into a collaborator by hand.

It holds no emitter logic: it never emits a line. That is what keeps the three emitters free to be reasoned about separately.
