Detailed Description

The bridge from Structured Text types to their C++ spelling.

Everything the generator knows about a type is decided here: the C++ name of an elementary type, the qualified name of a user-defined one, the way an array or a pointer decorates it, and the size and alignment a plain old value takes.

A named type may hide behind an alias, so the mapper keeps the alias table and chases it to the canonical type. The identifier case policy is part of the input, not of the state, so a mapper and the components that use it can never spell the same type two different ways.
