Detailed Description

A version constraint attached to a dependency.

The raw text is preserved verbatim; the parsed clause list is present so that full dependency resolution can be implemented without re-parsing the descriptor.

Check whether a concrete version satisfies every clause.

All clauses must hold (AND semantics). The evaluation is the minimal subset needed by the project loader; the wildcard/caret/tilde semantics documented in PROJECT_CONFIGURATION_SPEC.md apply.
