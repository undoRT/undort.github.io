Detailed Description

A single JSON document model node.

One struct discriminates on JsonType. Numbers keep both the parsed double and the exact lexical token (numberRaw) so that serializing a document round-trips values like "8", "0.0" or "1e3" verbatim. Object members are stored as an ordered vector of key/value pairs.

Canonical textual form of a scalar node.

Strings yield their contents, numbers their exact lexical form, booleans "true"/"false", null "null". Used by deserializers that need a scalar string representation (suffixes such as "T#500ms", enumerators, numeric literals).
