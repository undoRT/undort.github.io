Detailed Description

Type checker helper functions (stateless, operate on TypeInfo)

These are free functions in TypeSystem.cpp, not methods of a class.

Validate and type a binary expression for a given operator.

Comparison operators yield BOOL; logical/bitwise AND-OR-XOR map to BOOL or a common integral type; MOD requires integer operands only; arithmetic operators require numeric operands. Unsupported combinations are reported as diagnostics and yield an invalid TypeId.

Resolve a member access on a struct or function block instance.

Struct members are looked up in the type symbol's member list; FB locals, methods and parameters are resolved through the FB scope, walking the base-class chain, and interface methods through implemented interfaces. Failures are reported as diagnostics.

Validate and type a unary expression for a given operator.

NOT requires a BOOL operand and yields BOOL; unary "+"/"-" require a numeric operand and preserve its type. Unsupported combinations are reported as diagnostics and yield an invalid TypeId.

Parameters

symTabThe symbol table used to look up result types
Returns
The TypeId of the expression result, or 0 when invalid
