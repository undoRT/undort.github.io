Detailed Description

Expression and statement emission.

Emits the body of a function block, function or program: every statement form (assignment, IF, FOR, WHILE, REPEAT, CASE) and every expression form, plus the address read/write helpers and the ordered struct initializer they share. It reads and writes the shared EmissionContext.
