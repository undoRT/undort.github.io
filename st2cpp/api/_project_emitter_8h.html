Detailed Description

File assembly: the flat translation unit and the modular project.

Owns the two entry points of the generator. The flat entry emits one header and one source for the whole translation unit; the modular entry splits it into one file per function block, function, program and global list, plus the master headers that include them. It delegates declarations to the DeclEmitter and bodies to the BodyEmitter.
