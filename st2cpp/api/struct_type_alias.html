Detailed Description

Represents a named type alias or a named array type.

Covers TYPE Name : <TypeRef>; END_TYPE blocks, where the underlying type may be an elementary type (alias), another user type or an array:

  • TYPE MyInt : INT; END_TYPE
  • TYPE MyArr : ARRAY[0..9] OF REAL; END_TYPE The TypeRef holds the full underlying type (including array dimensions).
