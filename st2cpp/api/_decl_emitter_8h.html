Detailed Description

Declaration emission: POUs, structs, enums, globals and methods.

Walks the translation unit and emits the declarations into the header or source stream: function blocks, functions, programs, structs, interfaces, enums, global variables and methods, and the signature collection they rely on. Statement and expression bodies are delegated to the BodyEmitter.
