enum class st2cpp::library::FbMemberStorage
strong

The storage class a function block member lives in.

Mirrors the ST variable sections an FB member can be declared in. Parameters (VAR_INPUT/VAR_OUTPUT/VAR_IN_OUT) are not members: they are described by FunctionBlockDef::parameters instead.

Enumerator
Var 

VAR: state that persists across calls.

Temp 

VAR_TEMP: scratch valid for the duration of one call.

Retain 

VAR RETAIN: state that survives a warm restart.

Constant 

VAR CONSTANT.
