Detailed Description

Minimal self-contained JSON DOM, parser and serializer.

The JSON module is a small, dependency-free implementation used by the Library Descriptor pipeline (JSON file -> LibraryDescriptor). It provides a type-erased document model (JsonValue), a recursive-descent parser with line/column diagnostics (JsonParseError) and a serializer with configurable indentation. Object member order is preserved on both parse and dump.
