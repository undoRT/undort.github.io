Detailed Description

Data model of a Project Configuration (JSON -> C++ object model)

The Project Configuration describes "quali librerie usa questo progetto e dove trovarle" and is deliberately separate from the Library Descriptor, which describes "che cosa contiene una libreria". The configuration is consumed by the ProjectLoader, which loads each Library Descriptor into a LibraryRegistry, and ultimately by the SemanticAnalyzer through the bridge provided by the registry.

Version constraints reuse the Library Descriptor model (VersionConstraint) so that the constraint language and its parsing stay in one place.
