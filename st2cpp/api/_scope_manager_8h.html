Detailed Description

The symbol scope stack used while emitting a POU.

The generator walks nested scopes as it emits: the global scope, one per function block or program, then one per method or nested block. A name has to resolve to the C++ type it was declared with, not to the type of an unrelated symbol of the same name further out, so the lookup walks inward out and stops at the first hit. The manager also carries the AT address of a variable, the per-parameter temporary counter that keeps two output temporaries from colliding, and the base class a SUPER^ call resolves to.

It is intentionally free of the output streams so that both the declaration and the body emitters can share one stack.
