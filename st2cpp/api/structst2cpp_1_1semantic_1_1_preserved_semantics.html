Detailed Description

Preserved-semantics record (Fase 6)

Evidence that the decorated AST is a faithful, complete semantic model of the source. Consumed by the CLI to gate generation in Strict mode and by diagnostics: preserved() is true only when the analyzer ran and every identifier reference was resolved.
