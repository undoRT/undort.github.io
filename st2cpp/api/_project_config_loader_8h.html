Detailed Description

Loads a Project Configuration from JSON and validates it.

The loader is the entry point of the pipeline Project JSON -> ProjectConfig (validated) It parses the JSON document (via the st2cpp::json module) and validates the structure. Path semantics:

  • absolute paths are used verbatim;
  • relative paths are resolved against the directory that contains the configuration file (never blindly against the process working directory);
  • fromJson/fromString have no base directory, so they only validate and keep the declared path; ProjectConfigLoader::fromFile additionally fills LibraryEntry::resolvedPath.
