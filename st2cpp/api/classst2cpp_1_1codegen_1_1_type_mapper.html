Emit an explicit static_cast for RHS of an assignment/RETURN when the semantic types of lhs and rhs differ.

The semantic analysis already validated the assignment; the runtime types are C++ primitives, so the cast only makes the intended conversion explicit (IEC 61131-3 allows widening between numerics). No cast is emitted when the mode is disabled, types match, or the target is not numeric elementary.

Parameters

rhsRHS expression (decorated)

◆ registerTypeAliases()

void st2cpp::codegen::TypeMapper::registerTypeAliases ( const std::vector< TypeAlias > &  aliases)

Register named type aliases so mapType can resolve them.

This is the legacy (no-SemanticInfo) path: each alias is recorded with its underlying TypeRef. Aliases that map to another alias are chased lazily by resolveAliasLegacy on a per-use basis, so declaration order and in-order chains both work from the caller's perspective.

Parameters
aliasesThe TYPE aliases declared in the translation unit

◆ resolveAliasLegacy()

std::string st2cpp::codegen::TypeMapper::resolveAliasLegacy ( const std::string &  name) const

Resolve an alias name to its underlying C++ type (legacy mapType path).

Follows alias-of-alias chains through m_aliasTypes with a cycle guard; a chain target that is itself an alias keeps the lookup alive, and anything else is handed to mapType. Returns "" when the name is not a known alias, so callers can fall back to the plain name.

Parameters
nameThe (normalized) alias name to resolve
Returns
The resolved C++ type, or "" when not an alias / cyclic / broken
