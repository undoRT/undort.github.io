Detailed Description

Semantic Analyzer - performs semantic analysis on TranslationUnit.

Produces SemanticInfo containing SymbolTable, Diagnostics, and pre-computed maps. CodeGenerator can optionally use this for improved diagnostics and pre-computed data.

SemanticInfo st2cpp::semantic::SemanticAnalyzer::analyze ( const TranslationUnit &  tu,

Analyze a translation unit.

Run the full semantic analysis pipeline over a translation unit.

Parameters
tuTranslation unit to analyze
strictnessError handling mode (default: Permissive for migration)
Returns
SemanticInfo with symbol table, diagnostics, and pre-computed data

Executes the header-registration pass (DeclVisitor) followed by the body-visiting pass (BodyVisitor), then assembles the SemanticInfo result. Records the preserved-semantics evidence (mode, strictness and resolved identifier counts) and the AT placement addresses consumed by the CodeGenerator, keyed as "FBName::varName" for POU locals and "varName" for globals, skipping method-local variables.

Parameters
tuThe translation unit to analyze
strictnessThe strictness mode controlling IEC compliance checks
Returns
The populated SemanticInfo for the translation unit
