Detailed Description

The tasks of one PLC instance, with the Master settings they imply.

undoPLC drives every Worker from a single Master cycle, so the Master has to run at the finest cycle any of its tasks asked for and at a priority strictly above all of them: a task that overruns must never be able to delay the cycle that supervises it.
