Detailed Description

Options controlling a library export.

Structured Text cannot express library identity, so id/name/version (and the optional description) must be supplied externally (e.g. by a CLI). dependencyVersions is the explicit version policy for automatically derived dependencies: key = external library id (case-insensitive), value = version constraint text (e.g. "^1.0.0"). Versions are never invented: a used external library without a policy entry is an export error.
