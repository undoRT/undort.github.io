◆ orderedFbNamesFromSemantic()

std::vector< std::string > st2cpp::codegen::DependencyOrdering::orderedFbNamesFromSemantic ( ) const

The function block order the semantic analysis computed, when it has one.

Map the semantic fbTopoOrder (SymbolIds) to codegen FB names.

Only names of FB symbols that exist in the current m_fbMap are kept; names are normalized exactly like the legacy path (normalizeType). The semantic order already accounts for inheritance and composition dependencies.
