Detailed Description

End-to-end tests for the –export-descriptor CLI command.

These tests invoke the actual st2cpp executable (path injected through the ST2CPP_CLI_PATH compile definition) on temporary ST inputs and verify the produced JSON Library Descriptor and the process exit codes.
