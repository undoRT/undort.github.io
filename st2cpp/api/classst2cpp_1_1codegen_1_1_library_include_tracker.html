◆ computeLibraryIncludeLines()

void st2cpp::codegen::LibraryIncludeTracker::computeLibraryIncludeLines ( const TranslationUnit &  tu)

Pre-scan the TU and compute the sorted, deduplicated include lines.

Pre-scan of the translation unit that collects the include lines of the libraries that are actually used.

Parameters
tuThe translation unit about to be generated

Libraries are only included when used, never on every configuration load. Usage means: any declaration whose type resolves to an external library type (globals, POUs, struct members, FB instances) or any expression that references an external symbol (function calls, FB invocations, globals, constants, enumerators). Includes are deduplicated and sorted for a deterministic header.
