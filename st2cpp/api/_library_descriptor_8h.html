Detailed Description

Data model of a Library Descriptor (JSON -> C++ object model)

The Library Descriptor is the serializable representation of an external ST/C++ library (spec version 1.0). This header defines the in-memory model produced by LibraryLoader and consumed by the LibraryRegistry. It is deliberately independent from the SemanticAnalyzer: the two are bridged through the Registry, keeping the analyzer decoupled from the JSON layer.

Type references reuse the IEC 61131-3 elementary type enum BaseType from the AST so that the descriptor types stay conceptually compatible with the existing type system.
