◆ groupByPlc()

std::vector< PlcGroup > st2cpp::task::groupByPlc ( const TaskConfig &  config)

Group the tasks by PLC instance, preserving declaration order.

The first appearance of a plc value fixes its position in the result, and the tasks of a group keep the order they were declared in, which is the order the generated runtime registers (and starts) its workers.

◆ kMaxPriority

constexpr int st2cpp::task::kMaxPriority = 98
constexpr

Highest SCHED_FIFO priority a cyclic task may declare.

SCHED_FIFO tops out at 99 and the Master of a PLC instance needs a priority strictly above every task it supervises (see PlcGroup), so the top value is reserved for the Master and a task may not claim it.
