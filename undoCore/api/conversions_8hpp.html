Detailed Description

IEC 61131-3 standard type conversion functions.

Author
Salvatore Bamundo
Date
July 2026 SPDX-License-Identifier: GPL-3.0-or-later SPDX-FileCopyrightText: Copyright (c) 2026 undoRT

This header provides the runtime implementation of IEC 61131-3 standard conversion functions (Table 3 of the standard) used by code generated by the st2cpp compiler.

Rounding convention: Conversions from floating point to integer types follow IEC 61131-3 semantics: round to nearest, ties away from zero. This differs from a plain C++ static_cast, which truncates toward zero. Use TRUNC_* variants when truncation is required.

Date/time convention: DATE and DATE_AND_TIME are stored as seconds since 1970-01-01 UTC. TIME_OF_DAY and TIME are stored as milliseconds. All calendar decomposition is performed in UTC (gmtime), never local time, to keep conversions deterministic regardless of host timezone.
