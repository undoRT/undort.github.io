Detailed Description

One statement skeleton the suggestion list can write out.

The template is stored the way the statement reads, indented relative to the line the caret is on, so a nested skeleton is a matter of indenting the template rather than rewriting it. A "\t" in the template stands for one indent step and is widened to the editor's tab size on the way out.

The caret is stated against the template: caretLine counts template lines from zero, and caretColumn counts glyphs into that line before the base indentation is prepended. There is no placeholder character in the written text; the caret is placed inside it.
