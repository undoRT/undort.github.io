Detailed Description

One open ST file, held whole so it can be put back.

Everything openFile() reads out of the file, and nothing that can be worked out again from it: the AST, the semantic analysis and the source map are all derived, and keeping them would mean a snapshot that is stale the moment a character is typed.

The editor contents are the point of it. A tab that is still open has to come back showing what was in it, and reading the file off disk would give back the version on disk rather than the one being edited, which is the unsaved half of every change made since it was opened.
