Detailed Description

Resolved-symbol extraction for ST syntax highlighting.

Author
Salvatore Bamundo
Date
July 2026 SPDX-License-Identifier: GPL-3.0-or-later SPDX-FileCopyrightText: Copyright (c) 2026 undoRT

Turns a parsed TranslationUnit plus the st2cpp symbol table into a flat list of classified identifier tokens. Deliberately free of any UI dependency so the mapping (which identifier belongs to which category, at which position) can be exercised without a graphics context.

Coordinates are 1-based lines (as st2cpp reports them) and 0-based columns into the line, matching the editor's glyph indices.
