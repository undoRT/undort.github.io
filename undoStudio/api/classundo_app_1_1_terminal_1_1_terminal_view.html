Draw the session inside the current ImGui window.

Parameters
sessionSession to draw
fontMonospace font to draw with
fontSizeSize to draw it at, adjusted by Ctrl and the wheel
focusedWhether this pane holds the keyboard

The pane sizes the session to the space it was given, so a resize here is a real terminal resize as far as the shell is concerned. A larger font makes the cells larger and the session smaller: the grid cannot overlap, because every glyph is drawn inside a cell measured from that same font and size.

Turn this frame's key presses into what the session should be sent.

Parameters
sessionSession to send to
focusedWhether this pane holds the keyboard
fontSizeSize of the terminal, changed by the size keys
defaultSizeSize the reset key returns to

The size keys are answered here rather than in the panel, because the ones that matter arrive as characters and not as keys: on a layout where '+' is its own key, or typed as Shift and '=', the only thing ImGui reports is the character, so a check against a key code never sees it.
