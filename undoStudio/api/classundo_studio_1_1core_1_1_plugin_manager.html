◆ shutdownAll()

void undoStudio::core::PluginManager::shutdownAll ( )

Tear down and unload every loaded plugin, in reverse load order.

Must be called BEFORE ImGuiManager::shutdown(): plugin panels are std::function objects whose code lives inside the plugin's shared library, so ImGuiManager must forget about them before dlclose() unmaps that memory.
