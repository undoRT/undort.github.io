Detailed Description

Which severities the Output panel shows.

All are on to begin with, so the panel shows everything it used to. Turning the generated dump off is a separate switch on the panel rather than this one, because it is the one thing a user wants hidden by default and the one they want back when something looks wrong.

How many lines of a severity the list holds, filtered or not.

Counted from the whole list, never from what survived the filter: the number beside a switch is there to say what turning it on would show, so counting the already-hidden lines would leave every switch reading zero.
