Detailed Description

One entry of a completion list.

The same struct carries both kinds of completion: the members reachable through a '.' on a function block instance, and the plain names visible from where the caret is. They are shown in the same list, filtered and ranked the same way, so they share a type; only the set of Kind values is wider than a member needs.
