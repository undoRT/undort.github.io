void undoApp::Terminal::TerminalSession::sendChar ( uint32_t  codepoint,
VTermModifier  mod 
)

Send a character with modifiers held.

Parameters
codepointThe character, as a code point
modModifiers held with it

The way a letter is sent. Ctrl+C is this with 'c' and VTERM_MOD_CTRL, which the emulator turns into 0x03; a plain 'c' with the same modifier is the same interrupt.

Parameters
